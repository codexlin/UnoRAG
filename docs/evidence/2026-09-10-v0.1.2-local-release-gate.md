## 本次修复

1. Generation cleanup 不再通过 `app.active_document_generations` 视图请求 `FOR SHARE`。Worker 继续
   使用 document advisory lock 与 `app.documents ... FOR UPDATE`，和 generation activation 保持相同
   锁顺序，同时兼容最小权限 Worker 数据库角色。
2. 空文本和非法 UTF-8 分别保留稳定错误码 `document_ingest_empty`、`document_parse_invalid`，并在
   最近错误详情中显示可执行的原因、恢复建议和关联标识。
3. 本地 Compose 与 Dockerfile 移除硬编码开发版本，运行时版本统一回落到 `package.json` 唯一事实源。
