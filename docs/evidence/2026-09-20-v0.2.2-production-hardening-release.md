## 变更范围

`v0.2.2` 是稳定性加固版本，没有扩展新的 RAG 路径：

- 原生告警增加最小样本、连续超限、恢复去抖、去重与重试语义；
- 登录和 Public API 使用 Redis 分布式限流，依赖不可用时登录 fail closed；
- 密码轮换、成员移除和用户禁用可立即撤销旧 Session；
- 公网响应补齐 CSP、HSTS、X-Frame-Options、X-Content-Type-Options、Referrer-Policy 和 Permissions-Policy；
- 默认、高级、敏感配置分层，移除旧 Python/FastAPI 运行时入口和不再使用的依赖；
- 拆分 Library、Ask、入库事务和数据库 schema 等超大模块，不改变外部 API 与数据合同。

## 故障恢复与告警

- 停止 Qdrant 后 readiness 返回 503，`ask_ready=false` 且原因是 `qdrant_unavailable`；恢复后状态自动清除；
- 停止 Worker 后上传任务保持 queued，Worker 恢复后完成入库，后续 Ask、Public API、隔离、替换和删除均通过；
- Qdrant 故障持续越过控制周期后，`provider.qdrant` 告警打开；恢复并连续满足健康窗口后自动 resolved；
- 告警转移历史保留 `opened` 和 `resolved`，旧的 Ask P95 持续告警也已在新规则下正确恢复关闭；
- 故障注入结束后 lifecycle 再次全零。

生产 Webhook 目的地址按配置保持关闭，因此本次没有向外部系统发送测试通知。Webhook 请求签名、重复抑制、
重试和恢复事件已由真实基础设施集成测试覆盖；客户启用目的地址时仍应在自己的网络执行投递验收。
