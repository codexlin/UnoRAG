## 版本范围

`v0.2.0` 把复杂文档质量从汇总分数提升为独立发布合同，并补齐 Library 删除失败的管理员恢复闭环：

- 跨页表与低对比扫描分别拥有独立 scorecard；任一用例失败、证据类型错误或跨文档引用都会阻断发布；
- Provider scorecard 覆盖完成状态、partial、失败页、warning、解析 P50/P95、下游问题通过率和引用精度；
- 表格执行支持最多 50 个精确值，能够跨页和跨 row-group 返回多个命中行；
- Library 创建、修改、同步/异步删除、失败和重试通过 Request ID 进入统一审计；
- 删除失败可从运行中心发起新的幂等恢复任务，旧失败记录继续保留用于追责。

公开 `POST /api/v1/retrieve` 与 `POST /api/v1/ask` 契约未改变。

## 残余边界

- 这是单客户独立实例的 Compose 参考环境验收，不是公网共享多租户、Kubernetes 或任意客户网络拓扑认证；
- 未在当前在线实例执行破坏性原地 restore，客户仍需按自己的 RPO/RTO 演练恢复；
- `mixed-charts.pdf` 只验证图表周围叙事文字，ChartIR 和图表数值理解仍未实现；
- 万行级表格 SQL 执行不在产品范围，建议直接接入源数据库或专用查询工具；
- Ask P95 包含真实外部模型延迟，不应解释为所有 Provider、Region 或客户网络的容量承诺。
