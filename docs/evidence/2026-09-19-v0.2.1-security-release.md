## 评测器假失败处置

第一次运行得到 35/36，但失败题的真实答案和两条引用均正确，且答案明确包含缺失词“正常状态”。根因是
旧评测器只要在答案任意位置看到“非正常状态”，就会覆盖前文“正常状态（69.9%）”的正向命中。

PR #126 把判定改为逐个命中位置检查：至少一个非否定命中即通过，所有命中均被否定时仍 fail closed；
新增混合正向/否定回归后，完整 TypeScript core 与五项 PR CI 通过。修正后的评测器对未改变的 `v0.2.1`
线上应用重新执行全套新鲜入库和 41 个问题，得到上述 36/36、5/5 的干净 PASS。该修复只属于测试工具，
因此线上产品 revision 仍正确固定为 `eb0f45a`。
