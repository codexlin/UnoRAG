## 变更边界

`v0.2.3` 是发布可靠性维护版本，没有修改公开 Knowledge API、检索/回答路径、数据库 schema 或必需配置：

- 新增可执行的完整 release gate、Provider 故障注入、digest 升级回滚和破坏性恢复脚本；
- ARM 开发机必须显式声明平台模拟，并把该事实写入验收证据；
- 手动候选默认只发布 GHCR；ACR 需要显式选择，稳定 Tag 在完整配置下继续自动镜像；
- ACR pull/push 使用有界超时，避免镜像站长期阻塞发布流水线。

`v0.2.2` 的真实文件质量结果不冒充本版本新结果。本版本没有改变产品 RAG 路径，重点验证发布工具、故障
恢复和相同产品链路的回归；模型、Prompt、ParserProvider 或检索策略发生变化时仍必须重跑完整黄金集。
