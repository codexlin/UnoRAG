因此未发布、未升级香港正式实例。原始失败报告、日志、标签和镜像全部保留，不重跑覆盖或挪动标签。

关联 Request ID `3532e387-dd67-4fa8-bde5-1d646cc58ebe`：路由/计划/改写成功，retrieve 在 17 ms 失败；
PostgreSQL 同时记录 `invalid input syntax for type uuid`。新文档目录查询把 `service:` 命名空间身份
强制转换为 UUID。根因是本地 SQL 身份类型契约，不是 MinerU、模型或网络故障。

PR #210 将 ACL subject 转为文本后与完整 principal 比较，不剥离 `service:` 前缀，也不放宽权限。
真实 PostgreSQL 回归先 RED 复现，后 GREEN：Service Key 可读 Workspace 开放文档，但不能因为 UUID
后缀与用户相同就继承该用户的受限文档权限。新版本重新构建、签名、安装并完成 Public API smoke。
跟踪：[#205](https://github.com/codexlin/UnoRAG/issues/205)、
[#207](https://github.com/codexlin/UnoRAG/issues/207)、[#209](https://github.com/codexlin/UnoRAG/issues/209)。
