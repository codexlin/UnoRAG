# MeriKnow UI 主题：Northline 2.0（北线）

## 概念

企业知识问答要传达两件事：**可信**与**可循迹**。
主题名 **Northline**——像测绘里的子午线：冷静、精确、指向「有据可依」。
2.0 将产品从「带检索参数的聊天界面」推进为「企业证据工作台」。

刻意避开：紫渐变 AI 风、暖奶油+衬线杂志风、纯黑赛博风、大圆角胶囊按钮堆砌。

## 气质关键词

精确 · 冷静 · 证据感 · 日间办公友好 · 高信息密度

## 色彩

| Token | 用途 | 色值意向 |
|-------|------|----------|
| `--background` | 页面底 | 中性雾灰 `#F3F5F6` |
| `--foreground` | 主文字 | 炭墨色 `#172025` |
| `--primary` | 主按钮/强调 | 深海青 `#145B63` |
| `--accent` | 次强调/告警 | 测绘琥珀 `#B77818`（少用） |
| `--cite` | 证据高亮轨 | 海藻青 `#087A6A` |
| `--card` | 工作表面 | 纯白 `#FFFFFF` + 细描边 |
| `--border` | 分割 | 中性灰 `#D7DEE2` |

深色模式：墨底 + 冰川字 + 同色相青/琥珀，作夜间加班备用，默认仍以浅色为主。

## 字体

| 角色 | 字体 | 理由 |
|------|------|------|
| 品牌字标/公共首页 | **Fraunces** | 只承担品牌识别，不进入高密度工作区 |
| 界面标题/正文 | **IBM Plex Sans** | 企业可读、中西文稳 |
| 引用/日志 | **IBM Plex Mono** | 「证据编号」感 |

## 造型语言

- 圆角偏小（`0.375rem`），偏「工具」而非「消费 App」
- 面板：细边框 + 极轻垂直阴影，不用多层霓虹阴影
- 回答块：左侧 **2px cite 色竖线**，像审阅批注轨
- 背景：工作台使用纯色；子午线网格只允许出现在空状态或公共首页
- 动效：只用于新回答入场和证据轨道开合，并尊重 `prefers-reduced-motion`

## 工作台结构

```text
┌─ 顶栏：品牌 MeriKnow · 工作区切换 · 用户
├─ 侧栏：文库 / 问答 / 档案 / 设置
└─ 主区：查询记录 → 报告式回答 → 回答依据 + 右侧证据轨道
```

普通用户默认只看到答案、依据与服务状态。`hybrid`、`dense`、RRF
等工程信息放入链路抽屉或证据诊断区，不占据主阅读路径。

## 交互原则

- 引用不是回答后的附件，而是可核验答案的一部分。
- 表格、段落与页码定位优先于装饰性可视化。
- 技术诊断可达但不喧宾夺主；管理员和运维仍可完整排障。
- 动画表达状态变化，不表达“AI 正在施法”。
