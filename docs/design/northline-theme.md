# UnoRAG UI 主题：Northline（北线）

## 概念

企业知识问答要传达两件事：**可信**与**可循迹**。
主题名 **Northline**——像测绘里的子午线：冷静、精确、指向「有据可依」。

刻意避开：紫渐变 AI 风、暖奶油+衬线杂志风、纯黑赛博风、大圆角胶囊按钮堆砌。

## 气质关键词

精确 · 冷静 · 证据感 · 日间办公友好 · 轻地图/测绘隐喻

## 色彩

| Token | 用途 | 色值意向 |
|-------|------|----------|
| `--background` | 页面底 | 冷雾灰蓝 `#E9EEF2` |
| `--foreground` | 主文字 | 深墨青 `#0B1C24` |
| `--primary` | 主按钮/强调 | 深海青 `#0F4C5C` |
| `--accent` | 次强调/选中轨 | 测绘琥珀 `#C9852A`（少用） |
| `--cite` | 引用高亮轨 | 海藻青 `#1A7A6D` |
| `--card` | 面板 | `#F7FAFC` + 细描边 |
| `--border` | 分割 | `#C5D0D8` |

深色模式：墨底 + 冰川字 + 同色相青/琥珀，作夜间加班备用，默认仍以浅色为主。

## 字体

| 角色 | 字体 | 理由 |
|------|------|------|
| 品牌/大标题 | **Fraunces** | 有温度但不甜腻，区别于 Inter |
| 界面正文 | **IBM Plex Sans** | 企业可读、中西文稳 |
| 引用/日志 | **IBM Plex Mono** | 「证据编号」感 |

## 造型语言

- 圆角偏小（`0.45rem`），偏「工具」而非「消费 App」
- 面板：细边框 + 极轻垂直阴影，不用多层霓虹阴影
- 引用块：左侧 **3px cite 色竖线**，像批注轨
- 背景：淡子午线网格（细线 + 极低对比），不抢内容
- 动效：入场轻微上移淡入；悬停边框加深——克制

## SaaS 界面结构（后续）

```text
┌─ 顶栏：品牌 UnoRAG · 工作区切换 · 用户
├─ 侧栏：文库 / 问答 / 档案 / 设置
└─ 主区：问答台（主）+ 右侧引用抽屉
```

品牌在首屏要够大；工作台内再收敛为工具密度。

## 与 DustyKB 的差异

DustyKB 偏复古档案双线框；UnoRAG 偏 **现代测绘台**——更 SaaS、更冷静、仍强调「出处可循」。
